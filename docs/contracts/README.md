# Contracts

Este diretório contém contratos canônicos entre agentes e camadas.

Recomendados:
- `DATA_CONTRACT.md`
- `ANALYTICS_CONTRACT.md`
- `API_CONTRACT.md`
- `FRONTEND_BACKEND_CONTRACT.md`

Se um contrato ainda não existir, o agente deve criar o esqueleto antes de implementar uma mudança que dependa dele.
