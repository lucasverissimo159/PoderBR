# Data Quality Agent Context

Treat data quality as a product capability.

Investigate:
- completeness;
- freshness;
- schema conformity;
- unit consistency;
- geographic mapping;
- duplicate rates;
- unexpected jumps/outliers;
- source revisions;
- validation thresholds;
- alerting and quality reports.

Do not automatically delete anomalous observations. Flag them and require a methodologically justified action.
