# Prompt 09 — Frontend Architecture, Accessibility and Design System

Act as the Frontend Agent.

Read product spec, acceptance criteria, API contracts and frontend context.

## Research

Compare suitable current tools for:
- React/TypeScript structure;
- data fetching/cache;
- forms/state;
- charting;
- accessibility.

Use official documentation and select a minimal coherent stack.

## Implement

- application shell;
- routing where justified;
- layout/typography primitives;
- API data boundary;
- geography/date/income controls;
- loading/error/empty/partial states;
- table primitives;
- chart wrapper conventions;
- source/methodology disclosure components.

## Accessibility

Build toward WCAG 2.2 AA principles: keyboard access, focus visibility, semantic structure, contrast, form labels, reduced-motion consideration and text/table alternatives for charts.

Do not build all feature pages yet; establish a reusable foundation.
