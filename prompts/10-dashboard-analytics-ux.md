# Prompt 10 — Consumer Dashboard and Analytical Story

Act as Product UI + Visualization Agent.

Read product, methodology, API contracts, frontend architecture and acceptance criteria.

## Mission

Make the core answer understandable within seconds while preserving statistical honesty.

## Research

Investigate strong analytical dashboard patterns. Compare at least two information hierarchies and explain the selected one.

## Candidate hierarchy

1. location + income;
2. basket cost;
3. income burden;
4. affordability/quantity;
5. historical trend;
6. protein contribution;
7. comparison;
8. methodology/data coverage.

Treat this as a hypothesis and improve it through research.

## Requirements

Every chart needs units, dates, geography, baseline, accessible text equivalent and visible missing/estimated status.

Avoid simplistic green/red claims about general wellbeing. Use precise language such as “affordability relative to the selected basket”.

Implement the dashboard, comparison view and methodology/source disclosure. Add representative tests.
